# Resultados medidos (en git)

| Archivo | Contenido |
|---|---|
| `results.csv` | Una fila por instancia: cota de área, cota ponderada, y objetivo, brecha, tiempo y memoria de cada run (`cg27 report`). |
| `bounds.csv` | La cota de área ponderada de cada instancia y los números que la certifican (`cg27 bound`). |
| `submission_best.zip` | El archivo para subir al concurso. Pasa el verificador oficial: 250/250 (`cg27 submit --run best --check competition`). |

El resumen y las órdenes para regenerar todo están en `docs/resultados.md`.
